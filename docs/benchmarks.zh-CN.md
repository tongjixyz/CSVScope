# CSV Workbench 0.1.0 Preview：性能实测

测试日期为 2026-11-19 至 2026-11-20。除特别标明的目标外，下列数字均来自本机运行报告。**表中每个构建与缓存状态的数字取单次样本，OS 文件缓存未控制。**目前没有受控 OS 冷缓存及 P95 数据。

## 环境与测量口径

| 项目 | 本机实际环境 |
| --- | --- |
| CPU | Intel Core i5-14600KF，14 核 / 20 逻辑处理器 |
| RAM | 32GB；Windows 可见内存 33,382,004KiB，目标 16GB 环境待测 |
| OS | Windows 11 Pro，10.0.26300 |
| SSD | KIOXIA-EXCERIA G2、GV-1TB-2280；源与缓存位于 D: NTFS |
| 运行库 | 系统 Evergreen WebView2，最终便携版桌面回归观测到 157.0.4341.60 |
| 构建 | Rust 1.100.0 MSVC，release；锁定 Cargo/npm 依赖；DuckDB 原生 bundled 2.0.0 |
| 引擎配置 | 共享 memory_limit 2048MB、最多 4 线程、1 个重任务 |
| 缓存状态 | 表中初次准备使用无该文件应用缓存的独立目录；不主动清 OS 文件缓存 |
| 采样 | 约 200ms + CIM/进程检查耗时；磁盘约 1s + 检查耗时；采样峰值为实际峰值下界 |

CLI 时间从原生引擎调用计时；“原生预览”不包括 Tauri/WebView2/UI 绘制。桌面首屏通过真实 Glide 可访问单元格内容及两次动画帧观察，计时从打开文件开始。桌面准备和查询就绪轮询间隔 200ms，会引入观测误差。远跳与连续页的原生时间不包含用户操作和 UI 渲染。

内存分别报告 Private Bytes 和 Working Set。桌面统计包括应用主进程及观察到的全部 WebView2 子进程，不含 Playwright 测试驱动；CLI 只包括基准程序进程树，不把它称为整应用内存。工作集求和可能重复计算共享页。DuckDB 的 `memory_limit` 不是整个应用的硬上限。

## 数据集

生成器按照 MiB 目标写完最后一条完整逻辑记录，所以字节数可能略超过整 GiB。本报告 **1GiB = 1,073,741,824 字节**，不混用十进制 GB。

| 数据集 | 实际字节 | 数据记录数 | 列数 | 特征 |
| --- | ---: | ---: | ---: | --- |
| 常规 1GiB | 1,073,741,973 | 6,509,896 | 12 | 中文、前导零长编号、日期、引号/逗号；低基数重复 |
| 常规 5GiB | 5,368,709,179 | 32,549,469 | 12 | 同一确定性分布 |
| 常规 10GiB | 10,737,418,355 | 65,098,936 | 12 | 同一确定性分布 |
| 高唯一值 1GiB | 1,073,741,977 | 5,495,806 | 12 | 编号和多数列近 100% 唯一 |
| 宽表 1GiB | 1,073,747,033 | 161,699 | 500 | 横向按需投影 |
| 长文本 1GiB | 1,073,760,731 | 45,391 | 12 | 16,384 字符 payload、中文、引号及字段内换行 |
| 多文件 5×2GiB | 每份 2,147,483,704 | 每份 13,019,787 | 各 12 | 5 个独立源路径，共用引擎与任务预算 |

常规生成器的小区与 QCI 值存在确定性关联，因此基准中的联动候选可能仅有一个值；用户要求的“小区1→QCI 1、5”等正确性用独立四行 fixture 和集成测试验证，不以此性能数据代替语义验证。

## 真实桌面实测

1GiB，12 列，6,509,896 条记录，无该文件应用缓存：

| 指标 | 实测 |
| --- | ---: |
| 从打开文件到实际显示数据 | 0.926 秒 |
| 完整准备观测 | 16.688 秒 |
| 首次完整筛选 | 0.616 秒 / 65,099 条 |
| 联动候选查询观测 | 0.062 秒 |
| 全量文本排序观测 | 5.375 秒 |
| 远跳 | 结果位置 5,858,906；界面源记录号 91,000，与后端核对一致 |
| 取消到查询终态 | 0.0348 秒 |
| 全应用进程树峰值 Private Bytes | 2,419,523,584 字节（约 2.253GiB） |
| 全应用进程树峰值 Working Set | 2,464,538,624 字节（约 2.295GiB） |
| 最大观察进程数 | 7，包含 WebView2 |
| 页面异常 | 未观察到 JavaScript 页面错误 |

启动空窗口观测为 1.286 秒，其中包含外部自动化连接和页面握手，不作为严格“可交互时间”结论。

5×2GiB 桌面首次导入的原始记录包含五个标签各自的完整行数。第一份表格在打开后 0.955 秒显示，最先就绪的文件为 105.440 秒，五份全部就绪为 276.846 秒。该次测试在后续的滚动恢复检查失败，进程树峰值也未写出；准备结果与后续修复的复测分别保留。

最终发行版用同一组五份基础缓存复测。每份均重新强校验后命中缓存，五份全部可查询为 4.631 秒。切换后显示第一行耗时 0.041 秒，切回并恢复到结果第 500,000 条耗时 0.226 秒。第二份文件的筛选与第一份的默认视图保持独立。进程树采样峰值为 Private Bytes 738,766,848 字节、Working Set 846,602,240 字节，最多 7 个进程，包含 WebView2。这个采样覆盖复用与交互，五份首次导入的内存峰值仍待测。

最终发行版也复测了 500 列宽表。复用缓存时完整排序为 0.257 秒，跳到结果第 145,529 条为 0.228 秒；横向滚动至 `column_100` 并补列耗时 0.806 秒。固定列 `column_0`、新增显示列和源记录号 130,952 一并与后端核对，行位置和查询条件保持一致。该次 WebView2 进程树 Private Bytes 采样峰值为 441,933,824 字节。

排序结果包含可见列 Arrow 投影及 rid 索引，可能超过原始 CSV 大小；排序期间还可能存在引擎 spill，需同时留出空间。不同分类的峰值不一定同时出现，不能将分类峰值简单相加作为合计峰值。常规数据重复率高，基础表压缩比例不能推广到高唯一值数据。

默认未筛选未排序视图不生成第二份全量表。关闭/替换查询后结果缓存释放，基础缓存按租约及 LRU 复用。1GiB 的早期 CLI 报告没有磁盘采样，也有一个失真的主进程单独峰值字段；本表使用进程树采样字段，不引用该失真字段。

再次打开实测为原生预览 / 强验证完成：常规 1GiB 为 0.0106 / 0.826 秒，常规 10GiB 为 0.0109 / 7.870 秒。两次均报告基础缓存命中，OS 文件缓存未控制。即使基础缓存命中，Ready 仍等待全文件 BLAKE3 校验，预览可先显示。

## 可复现入口与原始记录

```powershell
.\target\release\csvbench.exe generate .bench\sample.csv 1024 12
.\scripts\benchmark.ps1 -Profile release -File .bench\sample.csv -Mode exercise -Cache .bench\sample-cache -Output .bench\reports\sample
.\scripts\desktop-smoke.ps1 -Release -Files @('.bench\sample.csv')
```

`exercise` 依次运行首次完整准备、首个及三次后续筛选、联动候选和搜索、筛选导出数量校验、全量排序、三次远页、二十次连续页、全列不同值和取消。重复运行同一缓存目录用于复用测试；初次导入应选新目录。不得把删除应用缓存称为 OS 冷缓存。

原始 JSON 位于工作区 `.bench/reports/`、`.bench/desktop-benchmark/`；用于文档的归档放在 `docs/benchmark-results/2026-11-19/`。每份报告记录源实际字节、行列数、构建与硬件；新版本报告另外包含二进制 SHA-256 和磁盘采样。

## 目标、待测与限制

- **初步目标**：常规 1GiB 本地 SSD 首屏约 2 秒；本机单次桌面样本为 0.926 秒，尚不能据此宣称 P95 目标达成。
- 16GB / Windows 10、无应用缓存+受控 OS 冷缓存、有应用缓存+OS 冷缓存、多次统计中位数/P95：待测。
- 真实通信数据、不同长文本分布、低选择性包含条件、不同 DPI 与中文输入法：仍需专项验证。
- 磁盘写满、进程内存耗尽、强杀恢复、损坏缓存、10GiB 全量导出、导出中途取消：待验收。
- 常规及离线 NSIS 安装器已构建。干净 Windows 安装、断网安装全过程及应用代码签名待验收，体积见实现与验收记录。
- 超大 DISTINCT、排序和远跳到尚未生成的位置可能需要等待，界面显示准备/生成状态；不承诺任意文件、任意筛选瞬间完成。
