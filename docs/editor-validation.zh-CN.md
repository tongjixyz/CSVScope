## 桌面操作闭环

使用 `scripts/desktop-smoke.ps1 -Release -BinaryPath <独立发行目录中的 csvscope.exe>` 启动程序，连接仅对该测试实例启用的本机调试端口，操作实际 Canvas 表格。

1. 打开 `fixtures/linked.csv`，联动筛选两列，验证候选集合、结果行数与撤销/重做。
2. 验证常驻倒三角；已筛选列显示绿色漏斗和底色，清除后恢复未筛选状态。
3. 在数据单元格右键，确认默认菜单事件被阻止；菜单包含“另存为 CSV…”，没有刷新、打印或分享。
4. 编辑完整单元格，关闭标签时出现未保存提示；设置黄色并撤销/重做。
5. Shift 连选三列，Ctrl 多选两列，右键隐藏；在列布局恢复；删除两列并撤销。
6. Shift 连选三行，Ctrl 多选两行，删除指定源记录并撤销；Delete 清空内容并撤销。
7. 粘贴两个字段，保留含逗号文本；Ctrl+S 打开另存为，确认默认保存全部记录和全部保留列。
8. 原生后端写出真实 CSV 和颜色配套文件，核对前导零编号、改动文本、逗号转义及颜色元数据；确认源文件字节不变，完整另存为后清除未保存标记。
9. 重新打开输出 CSV，确认黄色恢复且文件初始状态为未修改。

文件选择器响应在测试中固定为临时路径；未自动化操作 Windows 原生文件选择器的控件。`start_export`、CSV 写出、指纹与配套文件写入、重新打开均使用真实后端，没有模拟导出结果。

## 范围与后续验收

本记录是 0.2.0 的编辑正确性与桌面交互检查。`benchmarks.zh-CN.md` 的 GiB 级性能数字来自 0.1.0，不能视为本版大规模编辑、删除或标色的性能实测。16GB 内存、干净 Windows 安装和故障注入仍按实现状态文档继续验收。
