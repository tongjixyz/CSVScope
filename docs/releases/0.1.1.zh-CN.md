# CSVScope 0.1.1 Preview

本次维护版补充便携版运行日志和卡顿诊断，并将可能等待磁盘或引擎锁的桌面命令移到阻塞工作线程。前端状态轮询同一时刻只保留一个请求。

## 运行日志

默认位置为 `csvscope.exe` 旁的 `logs` 文件夹，窗口右上角提供“打开运行日志”。日志记录操作阶段、耗时、错误、后台进度、前端与原生窗口心跳、无响应和恢复事件。普通日志约 5 MiB 一个，保留最近十个；其他实例正在使用的文件保留。日志可在程序运行或卡顿时读取、复制。

日志位置回退、异常副本与排查步骤见 [运行日志说明](../diagnostics.zh-CN.md)。日志只在本地保存，发行 ZIP 和 Git 提交均不包含运行日志。

## 旧版卡顿结论

Windows 在 2026-11-20 00:36:52 记录旧版 `AppHangTransient`，程序随后自行恢复。旧版缺少持久化操作日志，无法确定当时具体阻塞在哪条业务操作；本次修改降低界面线程等待磁盘或引擎锁的风险，并为后续故障保留现场。

源码维护分支为 `codex/portable-diagnostics`，与并行编辑功能任务使用不同工作树。合并其他功能时需另行检查版本和兼容性。
